# Surima

## Link del proyecto publicado

https://surima.netlify.app/

## Descripcion

Landing page para Surima. Presenta contenido comercial de la marca con secciones visuales, carruseles y estructura enfocada en conversion.

## Tecnologias usadas

- Astro
- Tailwind CSS
- Swiper

## Requisitos

- Node.js 18+
- npm
- Cuenta de Netlify para despliegue

## Retos tecnicos

- Crear una landing estatica con secciones visuales y carruseles.
- Mantener una experiencia responsive con carga rapida.
- Organizar contenido comercial en componentes sencillos.
- Preparar despliegue en Netlify.
